Design Variants

Toggle between multiple versions of the same UI region inside any experiment — explore options live without rewriting code.

1
Ask for a few versions of the same thing The AI picks up on phrasing like “what if we tried…”, “show me with and without…”, or “A/B this” and wires them up as toggleable variants — instead of replacing what you already have.
"What if we tried a compact and a hero version of this card?"
2
Toggle live with the Variants chip When an experiment has variants, a floating Variants chip appears bottom-right. Click it (or press V) to open the panel and switch between options. The default option is marked with a small dot.

The chip sits quietly in the bottom-right of any experiment with variants. Click it to open the panel — each group toggles independently, and the dot marks the default.
  • Multiple groups work independently — card × dialog × menu can each have their own set.
  • The panel only shows groups that are currently visible on screen, so it stays quiet when you’re deep in a flow.
  • Variants inside dialogs or overlays are picked up automatically as they open.
